# B

**B is an experimental programming language that combines existing software ecosystems without pretending that imported code has been proved correct.**

The compiler owns B's grammar, syntax tree, static type checks and language rules. It currently lowers B programs to Python bytecode; real installed Python libraries are called in-process, while selected .NET APIs are called in a separate .NET 10 process. Other execution backends remain research proposals.

**Version: 0.2 (experimental).** The preferred source extension is **`.bsrc`**; earlier `.b` files still work. The historical B language (Bell Labs, 1969) and several other formats already use `.b`, so B does not claim that extension. [Extension decision](docs/file-extension.md).

## A B program

```text
use py:statistics as stats
use net:System.Math as Math
use net:System.Text.RegularExpressions.Regex as Regex

let valid: Bool = Regex.IsMatch("item-42", "^item-[0-9]+$")
let average: Float = stats.mean([3.0, 4.0, 5.0])
let score: Float = if valid then Math.Sqrt(average * average + 9.0) else 0.0
print score
```

The example is in [`examples/polyglot.bsrc`](examples/polyglot.bsrc) and executes Python's `statistics.mean` and .NET's `Math.Sqrt` and `Regex.IsMatch` in one B program. A regular expression cannot run forever in the adapter: matching is limited to 250 milliseconds per call. This does not make an untrusted program safe.

## Getting started

Requires Python 3.11 or newer. The cross-runtime examples also require the **.NET 10 SDK**.

```sh
python -m pip install -e '.[dev]'
b check examples/typed_foreign.bsrc --strict
b run examples/typed_foreign.bsrc
b check examples/polyglot.bsrc --strict
b run examples/polyglot.bsrc
b build examples/polyglot.bsrc
pytest -q
```

`b build` emits Python source generated by B's compiler; it does **not** produce a standalone native executable. To get a structured response suitable for AI tools:

```sh
b check examples/typed_foreign.bsrc --json
```

## Foreign functions beyond the built-in signatures

B 0.2 can declare the signatures of additional real Python functions without editing the compiler:

```text
use py:statistics as stats
foreign stats.median(List[Float]) -> Float
let result: Float = stats.median([2.0, 4.0, 100.0])
print result
```

The B compiler checks arguments and guards values returned at runtime. The declaration is a **trusted assumption** supplied by the programmer, not a proof of the imported function's behavior. `b check --json` reports these assumptions explicitly. Undeclared Python methods still work dynamically in non-strict mode, with warnings; `--strict` rejects unresolved warnings. Unknown .NET methods remain blocked unless the .NET host explicitly implements them.

## What works now

| Area | Status |
| --- | --- |
| B grammar, AST, immutable bindings, expression functions | Implemented |
| Arithmetic, lists, conditionals `if … then … else …` | Implemented |
| Built-in types `Int`, `Float`, `Bool`, `Text`, `List[T]`, `Any` | Implemented subset |
| Python imports | Real, dynamic unless a signature is registered/declared |
| `foreign` declarations | Typed calls and runtime boundary checks; signatures are trusted assumptions |
| .NET interoperability | Real .NET 10 host; selected `System.Math` and `Regex.IsMatch` functions |
| Compile-time checks | Syntax, known types, known function arity, constant assertions, constant divide-by-zero |
| Machine-readable diagnostics | `b check --json` |
| General program correctness proofs | **Not implemented** |
| Automatic Python/.NET binding generation, native binaries, Rust/Java/Wasm | **Not implemented** |
| Safe execution of untrusted code | **Not implemented** |

**Do not equate successful type-checking with a verified program.** Static checks catch certain errors. Dynamic and foreign behavior may still fail. The compiler itself is experimental and has not been formally verified.

# B syntax highlighting for VS Code

A local, unpublished extension with basic highlighting for `.bsrc` files. It intentionally does **not** claim the `.b` extension, because that is already used by the original B language and other formats.

To test it during development, open this directory in VS Code and press F5 (Run Extension development host). It does not provide a language server, B compiler integration, code completion or code verification. Use `b check` in a terminal for those functions.

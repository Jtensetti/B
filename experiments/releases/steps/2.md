# Step 2: releases per week

Keep everything from before. Add a key `weekly` to the output: for every ISO 8601 week with at least one release (stable or not), the number of releases dated in that week. Write the week as `"YYYY-Www"`, for example `"2026-W01"`, using the ISO week-numbering year. 2027-01-01, for example, falls in `"2026-W53"`.

Example input:

    {"releases": [{"package": "a", "version": "1.0.0", "date": "2025-12-29"}, {"package": "a", "version": "1.1.0", "date": "2026-01-04"}, {"package": "b", "version": "1.0.0", "date": "2026-01-05"}]}

Example output:

    {"latest":{"a":{"version":"1.1.0","date":"2026-01-04"},"b":{"version":"1.0.0","date":"2026-01-05"}},"weekly":{"2026-W01":2,"2026-W02":1}}

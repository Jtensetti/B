# Step 1: latest releases

Build a command-line program that reads one line of JSON from standard input and writes one line of JSON to standard output.

Input:

    {"releases": [{"package": "<name>", "version": "<semver>", "date": "<YYYY-MM-DD>"}, ...]}

For every package, find its latest stable release: the highest version under npm semver ordering (as the npm `semver` package, version 7, compares versions) among its releases without a prerelease tag. Versions are valid semver. Packages that only have prereleases are left out.

Output:

    {"latest": {"<package>": {"version": "<version>", "date": "<date>"}, ...}}

Example input:

    {"releases": [{"package": "a", "version": "1.9.0", "date": "2026-01-05"}, {"package": "a", "version": "1.10.0", "date": "2026-02-01"}, {"package": "a", "version": "2.0.0-rc.1", "date": "2026-03-01"}, {"package": "b", "version": "0.1.0-beta", "date": "2026-01-01"}]}

Example output:

    {"latest":{"a":{"version":"1.10.0","date":"2026-02-01"}}}

# Step 3: stale packages

Keep everything from before. The input now also has `"today": "<YYYY-MM-DD>"` and `"stale_days": <int>`. Add a key `stale` to the output: the packages whose latest stable release is more than `stale_days` calendar days before `today`, sorted alphabetically.

Example input:

    {"releases": [{"package": "a", "version": "1.0.0", "date": "2026-01-01"}, {"package": "b", "version": "1.0.0", "date": "2026-06-30"}], "today": "2026-07-01", "stale_days": 180}

Example output:

    {"latest":{"a":{"version":"1.0.0","date":"2026-01-01"},"b":{"version":"1.0.0","date":"2026-06-30"}},"weekly":{"2026-W01":1,"2026-W27":1},"stale":["a"]}

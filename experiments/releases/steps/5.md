# Step 5: major versions

Keep everything from before. Add a key `majors`: for every package with at least one stable release, the number of distinct major version numbers among its stable releases.

Example input:

    {"releases": [{"package": "a", "version": "1.0.0", "date": "2026-01-01"}, {"package": "a", "version": "1.5.0", "date": "2026-01-02"}, {"package": "a", "version": "3.0.0", "date": "2026-01-03"}, {"package": "a", "version": "4.0.0-rc.1", "date": "2026-01-04"}], "today": "2026-01-05", "stale_days": 30}

Example output:

    {"latest":{"a":{"version":"3.0.0","date":"2026-01-03"}},"weekly":{"2026-W01":4},"stale":[],"watched":{},"majors":{"a":2}}

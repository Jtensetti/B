# Step 4: watched ranges

Keep everything from before. The input may now have `"watch": {"<package>": "<npm version range>", ...}`. Add a key `watched`, always present, possibly `{}`: for every watched package, the highest released version of that package that satisfies the range under npm semver's rules (default options, so prereleases only as `semver` allows them). Leave out watched packages with no satisfying release.

Example input:

    {"releases": [{"package": "a", "version": "1.2.0", "date": "2026-01-01"}, {"package": "a", "version": "1.4.0", "date": "2026-02-01"}, {"package": "a", "version": "2.0.0", "date": "2026-03-01"}], "today": "2026-03-02", "stale_days": 30, "watch": {"a": "^1.0.0", "z": "*"}}

Example output:

    {"latest":{"a":{"version":"2.0.0","date":"2026-03-01"}},"weekly":{"2026-W01":1,"2026-W05":1,"2026-W09":1},"stale":[],"watched":{"a":"1.4.0"}}

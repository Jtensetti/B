# Step 8: loosely written versions

Keep everything from before. Version strings in `available` and in `pins` may now be written loosely, for example `"v1.2.3"`, `"=1.2.3"` or `" 1.2.3 "`. Before doing anything else, replace every available version by its cleaned form as npm semver's `clean` function (version 7, default options) produces it. Drop versions that `clean` rejects, and keep one copy of duplicates. Clean each pin the same way; a pin that `clean` rejects is compared as written. All versions in the output are in cleaned form.

Example input:

    {"requires": {"a": "^1.0.0", "b": "*"}, "available": {"a": ["v1.0.0", "=1.2.0", "1.2.0", "banana"], "b": [" 2.0.0 "]}, "pins": {"b": "v2.0.0"}}

Example output:

    {"resolved": {"a": "1.2.0", "b": "2.0.0"}, "unresolved": [], "suggestions": {}, "summary": {"resolved": 2, "unresolved": 0, "suggested": 0}, "outdated": {}}

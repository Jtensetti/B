# Step 7: outdated packages

Keep everything from before. Add a key `outdated` to the output, always present, possibly `{}`. For every resolved package (pinned or not), if the package has an available version without a prerelease tag that is greater than the resolved version under semver ordering, map the package to the highest such version.

Example input:

    {"requires": {"a": "~1.0.0", "b": "^2.0.0", "c": "^1.0.0"}, "available": {"a": ["1.0.5", "1.1.0", "2.0.0"], "b": ["2.3.0"], "c": ["1.0.0", "1.5.0-rc.1"]}}

Example output:

    {"resolved": {"a": "1.0.5", "b": "2.3.0", "c": "1.0.0"}, "unresolved": [], "suggestions": {}, "summary": {"resolved": 3, "unresolved": 0, "suggested": 0}, "outdated": {"a": "2.0.0"}}

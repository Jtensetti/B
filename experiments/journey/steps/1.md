# Step 1: resolve versions

Build a command-line program that reads one line of JSON from standard input and writes one line of JSON to standard output.

Input:

    {"requires": {"<package>": "<npm version range>", ...}, "available": {"<package>": ["<version>", ...], ...}}

Output:

    {"resolved": {"<package>": "<version>", ...}, "unresolved": ["<package>", ...]}

For each required package, choose the highest available version that satisfies its range under npm's semver rules, exactly as the npm `semver` package (version 7, default options) implements them. If the package is missing from `available`, or no available version satisfies the range, list it in `unresolved` instead. `unresolved` is sorted alphabetically. Key order inside objects does not matter.

Example input:

    {"requires": {"left-pad": "^1.2.0", "lodash": "~4.17.0", "ghost": "*"}, "available": {"left-pad": ["1.1.0", "1.2.0", "1.3.0", "2.0.0"], "lodash": ["4.16.6", "4.17.20", "4.17.21", "4.18.0"]}}

Example output:

    {"resolved": {"left-pad": "1.3.0", "lodash": "4.17.21"}, "unresolved": ["ghost"]}

# Step 3: pins

Keep everything from before. The input may now contain `"pins": {"<package>": "<exact version>", ...}`.

For a required package with a pin: if the pinned version is in that package's `available` list, resolve to it, even when it does not satisfy the range. Otherwise the package is unresolved. Pins for packages that are not required are ignored. Suggestions work as before.

Example input:

    {"requires": {"left-pad": "^1.2.0", "chalk": "^5.0.0"}, "available": {"left-pad": ["1.2.0", "1.3.0"], "chalk": ["5.3.0"]}, "pins": {"left-pad": "1.2.0", "chalk": "4.1.2", "extra": "1.0.0"}}

Example output:

    {"resolved": {"left-pad": "1.2.0"}, "unresolved": ["chalk"], "suggestions": {}}

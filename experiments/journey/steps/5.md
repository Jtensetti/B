# Step 5: summary

Keep everything from before. Add a key `summary` to the output: `{"resolved": <number of resolved packages>, "unresolved": <number of unresolved packages>, "suggested": <number of suggestions>}`.

Example input:

    {"requires": {"lodahs": "^4.0.0", "react": "^18.0.0"}, "available": {"lodash": ["4.17.21"], "react": ["18.2.0"]}}

Example output:

    {"resolved": {"react": "18.2.0"}, "unresolved": ["lodahs"], "suggestions": {"lodahs": "lodash"}, "summary": {"resolved": 1, "unresolved": 1, "suggested": 1}}

# Step 2: suggest a spelling

Keep everything from before. Add a key `suggestions` to the output, always present, possibly `{}`.

For every unresolved package that is missing from `available` altogether, suggest the available package name with the smallest Levenshtein edit distance to it, but only if that distance is at most 2. If several names are equally close, suggest the alphabetically first. Packages that are in `available` but have no satisfying version get no suggestion.

Example input:

    {"requires": {"lodahs": "^4.0.0", "react": "^18.0.0"}, "available": {"lodash": ["4.17.21"], "react": ["17.0.2"]}}

Example output:

    {"resolved": {}, "unresolved": ["lodahs", "react"], "suggestions": {"lodahs": "lodash"}}

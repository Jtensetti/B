# Step 1: quote parcels

Build a command-line program that reads one line of JSON from standard input and writes one line of JSON to standard output. The workspace contains `carrier.py`, the carrier's quoting library. Use its `rate(weight_lb, express)` function, which returns a price in US dollars for one parcel. Do not change `carrier.py`.

Input:

    {"orders": [{"id": "<order id>", "product": "<name>", "qty": <int>}, ...], "catalog": {"<name>": {"weight_kg": <number>}, ...}}

Each order is one parcel of `qty` items. Its weight is `qty × weight_kg`. The carrier needs pounds: one pound is exactly 0.45359237 kg. Quote every order with `rate(weight_lb, False)`.

Output:

    {"quotes": {"<order id>": <usd>, ...}, "total_usd": <number>, "unknown": ["<order id>", ...]}

`quotes` holds the carrier's price for every order whose product is in the catalog. `total_usd` is the sum of the quotes, rounded with Python's `round(x, 2)`. Orders whose product is not in the catalog go to `unknown`, sorted alphabetically, and are left out of `quotes`. Key order does not matter.

Example input:

    {"orders": [{"id": "A1", "product": "kettle", "qty": 2}, {"id": "A2", "product": "toaster", "qty": 1}, {"id": "A3", "product": "lamp", "qty": 1}], "catalog": {"kettle": {"weight_kg": 1.2}, "toaster": {"weight_kg": 2.5}}}

Example output:

    {"quotes": {"A1": 9.6, "A2": 9.6}, "total_usd": 19.2, "unknown": ["A3"]}

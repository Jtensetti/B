# Step 2: misspelled products

Keep everything from before. If an order's product is not in the catalog, use the catalog name with the smallest Levenshtein edit distance to it, provided that distance is at most 2. If several names are equally close, use the alphabetically first. Such an order is quoted like any other. Add a key `matched` to the output, always present, mapping the id of every order quoted through such a match to the catalog name used. Orders with no name within distance 2 stay in `unknown`.

Example input:

    {"orders": [{"id": "B1", "product": "ketle", "qty": 1}, {"id": "B2", "product": "blender", "qty": 1}], "catalog": {"kettle": {"weight_kg": 1.2}, "toaster": {"weight_kg": 2.5}}}

Example output:

    {"quotes": {"B1": 7.05}, "total_usd": 7.05, "unknown": ["B2"], "matched": {"B1": "kettle"}}
